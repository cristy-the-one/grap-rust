    Knowledge Extraction Engine

    Propose an ontology from documents: the LLM extracts fragments, grap reconciles near-duplicate concepts by embedding similarity, and the result is versioned as a proposed candidate for review — it does not become active until you load it.

    Reads .md/.txt/.json (e.g. the Romanian legal acts). LLM via GRAP_LLM_BASE_URL (local Ollama); embeddings local. One LLM call per chunk — cap Max files on big corpora. GRAP_LLM_STUB=1 dry-runs offline.
